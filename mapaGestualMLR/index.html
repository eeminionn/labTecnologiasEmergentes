Ajustes

Google Maps requiere Maps JavaScript API y facturación. La clave se guarda solo en este equipo. Referrer: http://127.0.0.1:47831/*

La cámara se procesa localmente. Los mapas sí usan Internet. Los puntos azules son datos ficticios para probar selección.

Gestos

  1. Apuntar

    Extiende solo el índice y mueve la mano sobre la mesa. La sombra azul aparece sólo con una mano detectada; el punto disponible se resalta.

  2. Clic

    Coloca la sombra en el punto o botón y forma OK: une pulgar e índice con los otros dedos extendidos. Mantén la mano quieta 3 segundos. El aro se completa y selecciona automáticamente; no hace falta soltar. Abre la pinza antes de seleccionar otra vez. Soltar antes, mover la mano o añadir otra cancela la carga.

  3. Mover

    Forma OK con ambas manos, espera un instante y muévelas juntas en la misma dirección. Suelta cualquiera de las pinzas para detenerte.

  4. Zoom

    Con ambas manos en OK, sepáralas para acercar; júntalas para alejar. Suelta cualquiera de las pinzas para terminar.

Manos separadas, cámara fija, iluminación uniforme y fondo mate. Usa Ajustes para elegir tu USB, rotar y calibrar. Espacio pausa; Esc cancela cualquier acción.

Servicios de mapa: OpenStreetMap · Términos Google Maps · Privacidad Google. Los mapas usan Internet; este prototipo no envía frames de cámara al proveedor del mapa.
