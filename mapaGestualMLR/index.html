        Mapa base

        El mapa se vuelve a abrir al guardar el cambio de proveedor.

        La clave queda guardada en este equipo.

        Requisitos de la clave

        Activa Maps JavaScript API y facturación. Autoriza el origen http://127.0.0.1:47831/*.

        Ayuda

        Usar el mapa

        • Mapa

          Arrastra para moverte, usa + y − para acercar o alejar y selecciona un pin para ver su tema.

        • Análisis

          Elige qué ver y ajusta el período o el área. Señala un sector o marcador para consultar su detalle.

        • Información complementaria

          Se abre en otra ventana y se actualiza con lo que seleccionas en el mapa.

        Con el teclado, usa Tab para recorrer los controles y Enter para seleccionarlos. Pulsa Esc para cerrar las opciones abiertas.

        Control con las manos

        Pulsa Activar gestos y muestra la mano completa a la cámara, con buena luz.

        1. Seleccionar

          Mantén el índice sobre el punto o botón durante 1,5 segundos. Retíralo antes de volver a seleccionar.

        2. Mover

          Cierra la mano en puño y muévela. Abre la mano para detenerte.

        3. Acercar o alejar

          Forma un círculo con el índice y el pulgar de cada mano. Separa las manos para acercar o júntalas para alejar.

        Con el foco libre, Espacio pausa o reanuda los gestos. Esc cancela el gesto en curso.

        Fuentes y privacidad

        El mapa base necesita Internet. La imagen de la cámara se procesa en este equipo.
